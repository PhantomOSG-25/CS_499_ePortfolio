## Artifact: Software Design and Engineering

[View Artifact](artifacts/)

This artifact is a thermostat system developed using Python in a Linux-based Raspberry Pi environment.

### System Capabilities

- Reads real-time temperature data  
- Accepts user input for system setpoints  
- Controls heating and cooling indicators  
- Displays system data  
- Sends data over serial connection  

### Enhancements

- Reduced repeated code  
- Added centralized logging  
- Improved error handling  
- Improved system structure
