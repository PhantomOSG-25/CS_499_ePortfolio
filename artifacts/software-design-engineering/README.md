# Software Design and Engineering Artifact

This artifact is based on a thermostat system developed using Python in a Linux-based Raspberry Pi environment.

## Overview

The system integrates hardware components, including a temperature sensor, LEDs, buttons, and an LCD display.

## Contents

- original/ contains the initial implementation  
- enhanced/ contains the improved version  

## Enhancements

- Reduced repeated code using helper functions  
- Added centralized debug logging  
- Improved error handling  
- Separated LED logic from core logic
